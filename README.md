# EMEC landing site

Marketing website for EMEC (Environmental Management & Engineering Consultant), Dhaka. It is built with Next.js (App Router) and TypeScript and exported as a fully static site.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static site in ./out, deployable to any static host
```

- Site copy and data: `src/content/`
- Sourced company facts: `knowledge/`
- Session log: `PROGRESS.md`
