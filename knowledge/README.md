# EMEC knowledge base

These notes are facts extracted from EMEC's reference documents, for use as website copy. Every section cites its source file. Where sources conflict, all values are shown. Personal data (individual contact details, bank details, tax IDs, CVs, timesheets) is deliberately left out.

## Notes

- [company.md](company.md): identity, founding, office and contacts, approach, staff by discipline, equipment and software, countries.
- [services.md](services.md): service lines from the profiles, plus sub-activities taken from project records.
- [projects.md](projects.md): the full project table (41 entries, deduplicated), contract values, and project narratives.
- [team.md](team.md): key professional personnel (qualification, years, expertise), with years compared across profile versions.
- [clients.md](clients.md): client lists, other clients from project records, partner and associated firms.
- [digital-case-studies.md](digital-case-studies.md): River Revetment GIS, JICA web-GIS ToR, UFD sub-tool, Omchhu AMS, LIC Dashboard proposal and in-house SaaS, and a note on PDS.
